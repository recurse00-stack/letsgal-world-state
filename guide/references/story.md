# 在原剧情中检查与演出

在同一片段写好公共开场与收尾，在中间插入“执行状态规则”，生成调用位置编号。用 branch 编排分支，各项依次求值，第一项满足后运行对应 steps。仅有 steps 的末项用作兜底。分支可以运行三段、两段或空序列。规则可以嵌套，多个独立影响可分成多个步骤。

```json
[{"kind":"branch","branches":[{"condition":{"op":"arg","path":["hasLetter"]},"steps":[{"kind":"macro","id":"shop"}]},{"steps":[]}]}]
```

将 remember 设为 true，当前调用位置保留首次路线；给 scope 传角色编号可按人区分。首次获奖与再次播放同一段剧情是两个独立条件。要共享商店演出，在“共享演出”建立一项并选择原生章节及片段，把示例 shop 改为该项实际编号。多个调用位置引用同一宏。局部演出可从调用检查器选择原生片段，以 fragment 步骤引用。

在工作台打开“对白模板”。给旁白和需要出声的角色各建一个模板，目标片段内放一张原生旁白或对应角色的对话卡，正文填写 `{mixing-entropy.world-state.lineText}`。在方法块的“动作编排”里添加“局部对白”，逐行填写角色、台词和可选配音的素材路径。同一角色的各句共用一个模板。一句变两句只需在命中的分支中多写一行。需要镜头、立绘或交互选项时，先在 Studio 的原生片段编辑器编好，再在该分支加入“原生片段”选取它。

自由问话可写一个选择和三份交谈。每次问完返回选择。若乙提供账本线索，就在甲的交谈开始时读取这条线索。若甲先来过，乙提供线索后回访甲，也能触发追问。要记第一位受访者，初次交谈才写 first。展示选项、点击和真正开门时可分别安排一次判断。

监听按事件和作用域启用。进入广场时显式发送 enter。监听匹配后再看当地天气、防护并写入 wet；撑开伞只改变下一次检查，烘干动作可单独把 wet 清除。作者能把防护放在事件入口或监听内条件。每帧移动、碰撞和战斗回合可由独立子层组织。
