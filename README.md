# 世界状态 0.1.0（测试版）

世界状态是 LetsGal Studio 的叙事插件。我们希望为复杂、非线性、多条线索可以交错推进的作品提供搭建状态机雏形的底层。作者定义世界里有哪些对象、它们如何关联、何时检查条件，以及检查后播放什么、改变什么。剧情可以多次回到同一地点，每次依据玩家当时的经历给出不同回应。

**测试版使用建议**　目前的可视化编辑工作台还在完善，后续会继续调整界面与操作方式，也可能引入破坏兼容性的更新。现阶段建议先用小型工程或作品副本体验，暂缓让大型在制项目依赖本版。欢迎告诉我们哪一步难找、哪条规则难写，或哪段演出和预期不同。[提交体验反馈](https://github.com/recurse00-stack/letsgal-world-state/issues)

例如，广场上有甲、乙、丙三位证人。玩家先问乙得到一本账本，再问甲，甲会多说两句。若先问甲，拿到账本后再回来，也能追问。作者只需写一个广场入口、三份交谈，在甲的交谈中检查账本线索。公共开场、离场和返回广场的剧情都能复用。

## 可以用来做什么

| 创作需要 | 插件提供的能力 |
| --- | --- |
| 从人物找到当前天气 | 为人物、地点、天气建立类型与对象。字段可以保存数值、文字、开关、引用、结构、列表、片段或来源方法。从人物沿“所在地点 → 当地天气 → 修正值”读取。可用来源、编号、词条和字段限定范围，查询是否存在、数量、列表或唯一结果。 |
| 追踪某件物品的变化 | 执行生成时才为实例分配独立编号。同类物品可以共用类型与素材。一次生成十支箭后，交出其中一支只改那一支的归属。可把多个本地状态改动编成一批，校验通过后一起提交。 |
| 让同一步随情况变化 | 在剧情方法块调用条件或复用已保存的规则组，组合参数、对象字段、已有结果与其他规则。每处可以选择重新判断，或按调用位置和作用域记住首次路线。再次到访和读档恢复各有自己的语义。 |
| 明确何时触发影响 | 作者可以只在剧情走到某处时检查，或向监听发送事件。监听可以带标签，并按事件和作用域启用。例如进入雨中才检查遮雨防护；收起伞后，下次检查可写入“淋湿”，烘干再清除。 |
| 在一个片段里改变台词和演出 | 公共开场和收尾写一次。中间分支可以运行三个片段、两个片段或空序列，也可以插入逐句对白、角色与配音。原生片段保留镜头、立绘和选项，共享演出可以在多处调用。 |
| 让几个插件共同参与一次判定 | 接入的来源公开对象和带类型的方法，各自保存自己负责的事实。可以把某个来源的方法存在武器属性里，攻击时才把上下界传给取样来源，取回结果供伤害和附加效果使用。外部方法通过请求编号和回执衔接，读档可沿用同一次执行已有的结果。 |
| 编排顺序与并行 | 步骤可顺序运行，也可并行。作者可等全部完成、等首项完成，或直接继续；稍后按任务编号等待或取消待续任务，并为失败安排后续步骤。外部来源已经受理的操作由该来源核对回执。 |
| 区分回档、二周目与永久记录 | 普通存档恢复当时的世界状态、知识和执行进度。通关时，作者可指定从本次实际持有的知识中选哪些继承；新周目从所选通关记录开始。需要跨档保留的成就类事实可单独使用永久记录。 |
| 查出规则写错在哪里 | 在 Studio 的设置页维护资料，在方法检查器编排调用。可检查失效引用、字段类型、条件和来源方法，按需启用开发者日志，查看调用编号、失败位置和可用回执。 |

## 安装和第一次调用

1. 在[本版下载页](https://github.com/recurse00-stack/letsgal-world-state/releases/tag/v0.1.0)获取 `mixing-entropy.world-state-0.1.0.zip`。在 Studio 的扩展管理中导入扩展，将“世界状态”添加到目标作品并启用。安装目录的根层应有 `extension.json` 和 `dist/`。
2. 打开“世界状态”设置页，建立天气、地点和人物类型。添加“雨”“广场”和一个角色，将广场的天气指向雨、角色的地点指向广场。在雨的数值字段写入天气修正。
3. 在剧情中加入“执行状态规则”，为调用处生成独立编号。在分支条件中沿角色的地点和天气读取修正，分别填入满足条件和兜底时的对白或片段。改变天气，再次走到这里即可检验重入效果。逐句对白用到的原生模板见[剧情编排](guide/references/story.md)。
4. 配套包 `world-state-companion-0.1.0.zip` 包含可离线搜索的手册和 AI Skill。解压后直接打开 `guide-package/index.html`。若使用 LetsGal 主 Wiki，可登记到现有用户区；独立使用时也可以安装到 Agent 的技能目录。需要 Python 3.9 或更新版本，先预览，再加 `--apply` 安装。

```text
python install.py --user-area "<主 Wiki 用户区>"
python install.py --user-area "<主 Wiki 用户区>" --apply
python install.py --skills-root "<Agent 技能目录>" --apply
```

接入其他插件时，让提供方和调用方在作品的数据依赖页绑定相同的公开目录与调用集合，并约定方法参数、返回值和重复请求处理方式。[数据与关系](guide/references/data.md) · [跨插件协议](guide/references/providers.md) · [存读档与故障检查](guide/references/verification.md)

## 适用范围与验证

本版扩展 ID 为 `mixing-entropy.world-state`，SDK 声明为 `^3.0.0`。已在 LetsGal Studio 3.0.0-stable-r7、SDK 3.0.0 的独立作品中验证，并在独立桌面 Player 冷启动后读回三份普通存档。跨插件调用以两个独立示例来源验证；具体背包、知识、经济或随机数插件须按协议接入。其他宿主版本和渠道需在目标作品复核。

这个底层适合事件驱动的非实时探索。实时移动、碰撞或战斗回合可由独立插件负责，再通过接口交换参数和结果。需要新镜头或复杂演出时，先在 Studio 新建原生片段，随后在调用处选择。

## 从源码构建

使用 Node.js 22 和 npm，在仓库根目录运行 `npm ci`、`npm test`、`npm run build`。产物为游戏运行入口 `dist/index.mjs` 和 Studio 工作台入口 `dist/studio.js`。通常只需下载本体和需要的资料包即可使用。
